# Soil Dataset

This repository contains a soil-related dataset generated by extracting
spectral information from Sentinel-2 satellite imagery for geographically
referenced soil samples.

The dataset was created as part of a research workflow aimed at supporting
soil classification and other geospatial machine-learning applications.

## Data Sources

### Soil reference points

The reference points used in this dataset originate from the
[OpenLandMap SoilSamples](https://github.com/openlandmap/SoilSamples)
dataset.

These points provide ground-truth information associated with soil classes.
Although the original dataset has global coverage, the initial case study
used points located in France.

### Satellite imagery

Spectral information was extracted from Sentinel-2 imagery made available
through the Copernicus programme.

The processing workflow was implemented using Google Earth Engine (GEE).

## Processing Workflow

For each soil reference point, Sentinel-2 imagery was processed according
to the following workflow:

1. Load the georeferenced soil sampling points.
2. Filter Sentinel-2 imagery by:
   - acquisition date;
   - area of interest;
   - cloud and shadow conditions.
3. Calculate additional spectral indices:
   - NDVI – Normalized Difference Vegetation Index;
   - BSI – Bare Soil Index;
   - NDBI – Normalized Difference Built-up Index.
4. Identify bare-soil observations using the Sentinel-2 Scene
   Classification Layer (SCL).
5. Retain pixels classified as bare soil (`SCL = 5`).
6. Generate daily Sentinel-2 mosaics.
7. Extract spectral values for each labelled soil point at a spatial
   resolution of 10 m.
8. Export the resulting observations as CSV files.
